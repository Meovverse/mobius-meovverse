# 墓时 · 内部攻略（完整版）

> 面向**研发 / QA / 演示**：完整流程、每个选择的精确后果、全部结局触发条件、
> flag 速查、跳章与速通办法。**含剧透**。
> 玩家向（不剧透）的文档是 `doc/游玩指引.md`；本文件只给团队内部用。

---

## 0 · 怎么开始

1. 编辑器 **F5**（或双击导出件）→ 标题封面。
2. 封面上**任意点击 / Enter** → 翻到 **「桌前的账本」（ResumePoint）**，分支选择在这一屏：
   - **无档**：只有「另起一本」；第一按＝把话挑明，**4 秒内再按一次**才真删档 → 进序章。
   - **有档**：`↑↓` 选「翻开它——接着上次写」或「另起一本」。
   - `Esc` 回封面（封面上的 `Esc` = 退出游戏，无边框窗口没有 ×）。
3. 存档在 `user://ledger_save.json`（Windows：`%APPDATA%\Godot\app_userdata\墓时\ledger_save.json`）。
   **账本即存档**，没有别的存档点。

## 1 · 操作

| 输入 | 作用 |
|---|---|
| 方向键 / WASD | 走路（仅墓园段） |
| Enter / 空格 | 确认 · 互动 · 推进对白/字幕 |
| **按住鼠标右键** | 擦（在碑面上画圈） |
| **按住鼠标左键** | 描（在发亮的浅斑里来回描） |
| 光标移到物件 · 点击 | 调查 / 选择（资料卡整卡可点） |
| `Esc` | 标题=退出；其它画面=返回 |
| 右上 `≡` | 常驻返回主菜单（任何章节都能救场） |

## 2 · 一句话流程

```
标题封面 → 桌前账本
  → 序章（2006·登记本）
  → 墓园走动（2026·走到 A 区 7 号）
  → 一章 碑上的名字 → 二章 查档 → 三章 两个日期 → 四章 韩梅
  → 五章 死者韩湘 → 六章 石料 → 七章 苏航的压力 → 八章 最危险的选择
  → 九章 真相拼合 → 十章 真相 → 十一章 最后的选择 → 十二章 立碑
  → 十三章 真相公开（真结局）→ 尾声 → 制作人员名单 → 回标题
```

> 路由由 `ChapterFlow.Next()` 按**完成标志（flag）**决定，不认场景自己。
> **墓园走动只出现一次**（序章之后）；之后各章直接相连，不再回墓道。

## 8 · QA / 演示：跳章与速通

- **跳章**：编辑 `ledger_save.json`，在 `Flags` 里补齐到目标章的"完成标志"即可。
  例：想直接看终章 →
  ```json
  "Flags": ["clue_16","stone_altered","clue_05","clue_06","clue_10","clue_13",
            "clue_15","ch7_done","ch8_done","timeline_built","ch10_done","evidence_fixed"]
  ```
  （要真结局再加 `identity_swap`、且不加 `money_taken`。）
  然后从标题「继续」，`Next()` 会路由到对应章。
- **编辑器直跑单章**：Godot 里选中 `res://scenes/Ch0X.tscn` 按 **F6**。
  注意：十三章要求 `TrueEndingReady`，否则会兜底回标题——先按上面的 flags 造档。
- **一章调试**：游戏内 **F9** 瞬间擦净日期区（跳过擦碑）。
- **墓园**：`RPGExplo` 默认**自由走**；回归测试链加启动参数 **`auto`**（自动寻路 + 截图 + 到点退出）；终章清明版加 `qingming`。
- **无头跑集成测试**：`Godot --headless --path . res://scenes/IntegrationTest.tscn`（退出码 0=全过）；
  或 `bash tools/test.sh`。

## 9 · 实现要点 / 踩过的坑（与攻略相关）

- **路由只认 flag**：`ChapterFlow.Next()` 用"下一章的完成标志是否已置"来判当前该演哪出；
  所以"某章没选到推进项"会**原地重演该章**，不是 bug。
- **必须选到推进项的章**：二章=B；三 / 四 / 五章=A；七章=推回信封；八章=摆开；十一章=A。
- **`identity_swap` 曾经缺失**（2026-10-07 修）：五章 A 之前没落这个 flag，
  导致 `TrueEndingReady` 恒假、十三章被判回标题，**真结局实际走不到**。已修 + 补回归断言。
- **四章 C 的结局二判定**（同日修）：`hanmei_line_dropped` 之前设了却没人触发；
  现按剧本在**进入五章时**触发结局二判定。
- **真结局判定在 `RunState.TrueEndingReady`**，十二章砸底座只是演出。
- 没有小地图/任务箭头；墓园里靠**亮柱信标 + ▼ 浮标**认路。
- 对话框、资料卡都是**可见控件**；第一章的擦/描是唯一"手感"关卡。
