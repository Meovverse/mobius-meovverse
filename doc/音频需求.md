## 四、交付规范（照此交，可直接机器验收）

1. **文件名 = 本文档 ID**，小写蛇形，平铺 `assets/audio/`（**不要**加 `A1_`/`bgs/` 前缀子目录，已被退回两次）。
2. 附降噪后的**响度表**：文件名 + 峰值 dBFS + 档位（S0/S1/S2/A）。
3. 档位：**S0 −20**（触觉级）· **S1 −14**（操作级）· **S2 −8**（事件级，全篇最响）· **A −30**（环境，几乎听不见）。
4. 循环件交 44.1kHz **ogg（Xiph libvorbis）**：`loop_*` 导入 Loop **关**（程序按住开环、松手即停）；`amb_*` 导入 Loop **开**。Godot 不认 opus/flac，ffmpeg 实验性 vorbis 编码会解码失败——必须真 libvorbis。
5. 一次性音效交 44.1kHz **16bit wav**，时长 = 需求 + 尾静音 ≤0.25s。
6. 单文件 ≤600KB；环境音 ≤1.5MB。
