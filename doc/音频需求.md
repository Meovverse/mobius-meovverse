# 墓石 · 音频与音效需求（Audio Brief）

> 配套：`doc/技术方案.md`（§4 六个动词）、`doc/玩法设计.md`（§10 进度与反馈）、`doc/美术需求.md`
> **本文档定义了全篇 38 个音频资产（30 个 `sfx_` + 4 个 `loop_` + 4 个 `amb_`，素材总时长约 115 秒）。所有文件名、时长、级别已定死。**
>

## 0. 三条原则

### 原则 1 · 每个声音都必须能在不看屏幕的情况下说出是谁发的

玩家会盯着碑面看，眼睛不离开。他必须靠耳朵知道"我刚才那一下有没有用"。
所以：**同一个动作在所有章节里必须是同一个音**，跨章节复用同一个文件，不做变体。

### 原则 2 · 声音是这个游戏唯一的"叙述"

没有 BGM、没有旁白、没有配音。声音要承担叙事：
一罐石粉打开的声音 = 一整段"我要把它磨掉"。
所以 **一次性事件的音要留白**（前后各 200ms 静音），让玩家听出"刚才发生了一件事"。

### 原则 3 · 反馈音不做距离衰减 ★

**这一条反直觉，但它很重要。**

这个游戏里几乎所有东西都在同一张桌子上或同一块石头上。如果用 Godot 默认的
`AudioStreamPlayer2D` 距离衰减，碑面上的音会随镜头微调忽大忽小，
玩家会**听不清自己动作的反馈**——而反馈是这个游戏唯一的进度条。

**做法：全部用 `AudioStreamPlayer`（2D，非 3D）。**空间感靠轻微的 `pan` 区分左右
（比如拓包在纸的左边敲就是左声道），**不靠音量衰减**。

唯一的例外是终章的水泥碎屑（那是真的在"远处一点"），但也只用 pan + 极轻的高频衰减。

## 1. 全局规格

### 1.1 格式

| 项 | 一次性音效 | 循环音（环境 + 持续动作） |
|---|---|---|
| 容器 | **WAV**（短音用 WAV，解码零延迟） | **OGG Vorbis**（体积小，长时间解码无所谓） |
| 采样率 | **44100 Hz** | 44100 Hz |
| 位深 | 16-bit PCM | — |
| 声道 | **单声道 mono**（Godot 自动转立体声） | mono |
| 时长 | 见清单 | 环境 20–40s（首尾可循环）；持续动作 2–4s（**必须可无缝循环**） |

### 1.2 命名规范

```
sfx_    一次性音效
amb_    环境循环（ambient）
loop_   持续动作的可循环音（描、走刀、擦）
```

全部小写 + 下划线，全英文，**不含中文**（避免某些平台的路径编码问题）。
例：`sfx_peel_paper.wav`、`sfx_trace_break.wav`、`loop_chisel_run.ogg`、`amb_graveyard.ogg`

### 1.3 响度分级（必读）

来源不同的素材拼在一起最常见的失败是**响度不一**：某个音比别人大 6 dB，
玩家会觉得"这个动作更重要"，于是被误导。

**统一按下面的分级做，不要按素材原样交付：**

| 级别 | dBFS 峰值 | 用在哪 | 例子 |
|---|---|---|---|
| **S0 触觉级** | −20 | 笔触级的反馈。玩家手在动，声音很轻 | 擦石粉、描、走刀、卡尺滑动 |
| **S1 操作级** | −14 | 界面操作 | 翻页、揭纸、笔写字 |
| **S2 事件级** | −8 | 一次性事件。**全篇最响的就是这一级** | 砸底座、撕纸、锤击、水泥裂开 |
| **A 环境** | −30 | 环境循环。**必须几乎听不见**，只在完全安静时才注意到 | 风、灯的嗡鸣、雨 |

**验收要求**：所有文件归一化到各自级别的峰值。交付时附一个响度表（文件名 + 峰值 dBFS）。

### 1.4 Audio Bus 布局（"没有 BGM"的技术落实）

```
Master                     0 dB     ← 什么都不挂
├── SFX                    0 dB     ← S0/S1/S2 全部音效
├── Ambience              −6 dB     ← 所有 amb_ / loop_（比 SFX 再低一档）
└── (预留 Music)           —        ← ★ 不创建
```

- **不创建 Music bus。** 引擎里一旦有了这个 bus，将来就有人会往里塞东西。
  不存在，就不会有 BGM。
- 换章节时，程序把 `Ambience` 总线做**交叉淡化**（2 秒）。这就是"环境音的换气"，
  是这个游戏唯一的"过场音"。
- `AudioListener` 数量：**1**。2D 游戏不需要 3D 监听器。

### 1.5 导入设置（Godot）

| 文件类型 | Loop | Compress | 备注 |
|---|---|---|---|
| `sfx_*` | **Disabled** | **Disabled**（WAV） | 零延迟。短音不要压缩 |
| `loop_*` | **Disabled**（手动控制） | — | ★ 见下方说明 |
| `amb_*` | **Forward** | Vorbis | |

> ★ **`loop_*`（描走刀、擦石粉）不要在导入设置里开 Loop。**
> 这些动作有开始和结束，循环要由程序控制（按住时播、松开时停）。
> 开成导入期循环会导致"松手了声音还在响"。

### 1.6 无缝循环的技术要求

`amb_*` 和 `loop_*` 必须能**无缝**播放。判定标准：**循环点上不能有爆音（click/pop）**。

做法：
- 录音或合成时**首尾各多录 1 秒**，然后做 200ms 的等功率交叉淡化。
- 波形上，首帧和尾帧的直流偏移要接近（|差值| < 0.005）。
- 低频（< 80Hz）要小心——人耳对低频接缝特别敏感，交叉淡化时**优先处理低频**。

程序会在验收时检查：把文件首尾各 1ms 拼接，如果峰值跳变 > 0.02 就打回。

## 3. 禁止清单（和禁止红框高亮是同一类约束）

**这些不要做。做了一样，游戏就掉价了。**

| 禁止 | 为什么 |
|---|---|
| ★ **任何 BGM / 旋律 / 和声 / 钢琴 / 弦乐** | `玩法设计.md` §10 定死的。一个音阶都别加 |
| ★ **"叮咚""确认""成就"式的 UI 提示音** | ★ 最大的诱惑。这类音会把游戏变成 App。玩家抄对日期时**不该听到"正确"**，只该听到笔尖的声音 |
| 金属铃声、App 通知音、系统提示音 | 同上 |
| **鸟叫、虫鸣、犬吠** | 墓园。安静得只有风。虫鸣会让场景变成"郊外公园" |
| 人声嘈杂、能听清的对话 | D7 的低语必须是**听不清字**的 |
| 配音 / 语音 | ★ **这是一个决策点，见 §6 Q1。**默认不做 |
| 金属撞击的"金属味"音色库音效（大量商业音效的默认审美） | 这个游戏的声音要**土**：石头、水泥、纸、粗布。不要科幻感 |
| 混响很长的音效 | 场景都是**近场**（手边的东西）。混响 = 距离感，这个游戏没有距离 |
| 频谱很宽的音效（金属、玻璃） | 会和 12px 像素风打架。**全篇的频率重心压在 200–2000 Hz** |

## 4. 素材从哪来

按项目实际（美术用 SD，程序写 C#），音频的现实路径有三条，建议混合使用。

### 4.1 素材库（免费商用）

| 来源 | 适合 | 授权 |
|---|---|---|
| **Freesound**（筛选 CC0） | 纸、笔、金属工具、环境 | CC0 / CC-BY。**只用 CC0**，避免署名义务 |
| **Sonniss GDC Game Audio Bundle** | 大型动作音、材质音 | 免费，含完整授权 |
| **Kenney**（kenney.nl/assets） | 干净的 UI/物件音 | CC0 |

⚠ 库里的音效**几乎都太"精致"**——混响长、频谱宽。要**大幅裁剪**：
砍掉混响、压低高频、只留下中频主体。宁可自己合成。

### 4.2 程序合成（推荐用于这些）

以下 12 个是**噪声类**音效，纯程序合成比找素材更准、也更符合这个项目要的东西：

```
A1  loop_brush_stone    擦石粉       滤波白噪声 + 慢速包络
A2  sfx_brush_pile      碎屑         短噪声 burst
A3  sfx_over_wipe       擦过头       低通后的噪声 + 一点点失真
A5  loop_chisel_run     走刀         短促噪声包络序列（带节奏）
C2  loop_caliper_slide  卡尺         极细高频噪声 + 长包络
D1  loop_cement_chip    水泥         多层噪声 + 随机稀疏 burst
D3  sfx_stone_drop      石头         低频瞬态 + 二次噪声
D10 sfx_stone_grind     磨碑         低通噪声 + 缓慢升降调
E1  amb_graveyard       风           棕噪声 + 极慢 LFO 调制
E2  amb_office_night    CRT 嗡鸣     15.7kHz 正弦 + 谐波 + 噪声底
E3  amb_archive         日光灯       100Hz + 谐波 + 极轻高频噪声
E4  amb_rain            雨           高频白噪声 + 稀疏随机水滴
```

## 5. 程序侧需求（`AudioDirector`）

需要写一个 Autoload，管这些事。**不要让章节代码各自 new AudioStreamPlayer。**

```csharp
// src/Core/AudioDirector.cs（Autoload: AudioDirector）
public partial class AudioDirector : Node
{
    // 一次性音效：按 key 播放，同 key 有最小重触发间隔（防连点糊成一片）
    void Play(string key);                 // 查表 sfx_<key>

    // 持续动作音：按住开始、松开结束。同一时刻只允许一个 loop_ 独占
    void LoopStart(string key);
    void LoopStop(string key, float fadeOut = 0.08f);

    // 环境音：切章节时交叉淡化 2 秒
    void SetAmbience(string key, float crossfade = 2.0f);

    // 全局：所有环境音再乘一个系数（终章要能压到 0 让玩家只剩水泥声）
    void DuckAmbience(float linear01, float time);
}
```

**必须有的三个约束**（不写就会出 bug）：

1. **`loop_` 独占**：A1（擦）和 A5（描）不能同时响。第一章的"擦"和"描"是两种手感，
   混在一起就废了。
2. **描断点时立刻停 A5**，改播 A6。哪怕晚一帧都会让人觉得"没断开"。
3. **D2（底座裂开）之后 `SetAmbience` 到 0**，停 1.5 秒。这是全篇唯一一次刻意的静音。

**资源表**：用 `data/sfx.json` 登记（key → 文件名 → 级别），
不要在 C# 里写死路径。跟 `美术需求.md` 一样，配置和代码分离。

## 8. 验收标准

```bash
# 程序会写 tools/audio.py check（与像素管线配套）
python3 tools/audio.py check assets/sfx/
```

自动检查：

- [ ] 文件名规范（`sfx_` / `amb_` / `loop_`），全部小写下划线
- [ ] 格式正确（sfx=WAV / amb,loop=OGG）
- [ ] 采样率 44100 Hz、**单声道**
- [ ] 时长在 §2 表的 ±30% 以内
- [ ] **峰值电平符合 §1.3 的分级**（超出 1 dB 报出来）
- [ ] **无缝循环检查**：`amb_*` / `loop_*` 首尾拼接的峰值跳变 < 0.02
- [ ] **直流偏移**：绝对值 < 0.005
- [ ] **频谱重心**在 200–2000 Hz（超出的报出来——混响和金属味音效会在这里露馅）
- [ ] `data/sfx.json` 里每个文件都有登记，反之亦然

人工事项：

- [ ] ★ `A1` / `A5` / `C2` / `D1` 按住 10 秒**听不出循环点**
- [ ] ★ `A6`（描断）和 `A3`（擦过头）**让玩家本能地想停手**——这是唯一的判断标准
- [ ] ★ `A8`（揭拓片）听起来像"一张纸从石头上被拿下来"，不是"唰"
- [ ] 通关一遍，**没有任何一个音让人想到"这是一个游戏"**

## 9. 特别提醒

**音频是这个游戏最容易被做坏的部分**，因为它听起来"不难"。

三条最容易犯的错：

1. **加了一个 UI 确认音**。就这一个。整个游戏从"有人在查一件事"变成"一个记账 App"。
2. **循环音没做无缝**。玩家按住擦 5 秒，循环点在第 3.2 秒响了一下。
   手感瞬间从"我的手"变成"一段音频在播"。
3. **音效太干净**。素材库的音效都是给动作游戏做的，频谱宽、混响长、有"质感"。
   这个游戏的声音要**土**、要**近**、要**闷**——因为所有东西都在你手边 30 厘米。

如果时间只够做 6 个音，就做这 6 个：

```
A8  sfx_peel_paper    揭拓片        ★ 第一个证据离手
A6  sfx_trace_break   描断了        ★ 断点重来
A3  sfx_over_wipe     擦过头        ★ 不可逆的代价
D2  sfx_base_crack    底座裂开      ★ 全篇高潮
D10 sfx_stone_grind   磨碑          ★ 玩家亲手销毁证据
E1  amb_graveyard     墓地风声      ★ 唯一的环境
```

**这 6 个音决定了这个游戏是什么。其余 28 个只是让它完整。**
