# 墓时 · 游玩指引

> 2D 像素 · 推理 · 单周目约 90 分钟 ｜ 只需要鼠标和键盘

---

## 怎么开始

双击运行（或在 Godot 里按 F5）→ 看到画面后**点一下鼠标**（或按 Enter）游戏开始。
> 窗口是**无边框**的：标题界面按 **Esc** 退出游戏。
> 若第一次点击没反应，是 Windows 把"给未聚焦窗口第一击"吃掉了——再点一次或按任意键即可。
开头是一桩 2006 年的旧生意——看完、按 Enter，就进入了故事正片。

## 操作总表（全篇就这些）

| 输入 | 做什么 |
|---|---|
| 方向键 / WASD | 走路 |
| Enter / 空格 | 确认 · 互动 · 推进画面 |
| **按住鼠标右键** | 擦（石粉、浮尘）。跟着出现的那只手画圈就行 |
| **按住鼠标左键**（在浅色斑块里） | 描。看到发亮的方框，按住左键在里面慢慢来回描——手移出也不会白描，回来接着走 |
| 拖动到物件上 · 点击 | 调查——光标停在哪，就在查哪 |
| Esc | 暂停/返回（演示版） |

没有小地图，没有任务标记，没有箭头。**画面里能看的都能碰，能碰的都该碰。**

## 这个游戏里你在干什么

你是个刻碑的手艺人。二十年前你给一位母亲刻了块碑；现在你发现碑上的日期
**不对**——石头是你亲手刻的，你记得每一刀。

你要做的不是找线索列表，是**用手确认**：把碑面上的灰擦开，把刻痕描完整，
把两张纸并起来对着光看，把卡尺卡在两个日期之间。

## 三个提醒（就够了）

1. **擦要有耐心，但别擦过头。** 擦到发亮还不停手，有些东西就永远看不清了。
   游戏不会提醒你——手会。
2. **你的账本就是进度。** 你抄下来的每一行都在里面；关掉游戏再打开，
   它还在那一页。没有别的存档点。
3. **答案不止一个方向。** 有些路口你选择不查，故事会走向别处——
   五个结局里有四个是"你本来可以看见"。

## 常见问题

**Q：卡住了怎么办？**
A：回墓道走走（走近碑按 Enter 再进去），或者把已经抄下来的东西并排看。
这个游戏里卡住的地方，答案一定已经在你的账本里了。

**Q：为什么没有教学？**
A：你有手。第一次擦碑时屏幕上会出现一只手示范——跟着它做就行，
它只出现一次。

**Q：想速通结局？**
A：第一块碑上，如果你不想继续看下去，转身离开就是第一个结局。
但你会想知道那一天到底发生了什么。
