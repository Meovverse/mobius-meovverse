# 墓时 · 自动化测试（#17）

> 答 Citrate657 #17：已有，且一直在用。一条命令跑全部机器可测项，退出码判过否。

## 一键运行

```bash
bash tools/test.sh
```

三步：① 编译（C#）→ ② 集成测试（`scenes/IntegrationTest.tscn`，headless）→
③ 墓园自动走链（`RPGExplo` 自动驾驶到 A 区 7 号）。**退出码 0 = 全过，1 = 有失败。**

## 集成测试覆盖什么（现 70 条断言）

| 组 | 覆盖 |
|---|---|
| 资产对账 | 槽位总数、待美术数、启动时不崩 |
| 音频 | 每条交付件是否可加载；缺口清单；登记表一致性 |
| 章节路由 | 新档→序章、序章→一章、……、证据齐→终章（flag 推演） |
| 第一章玩法 | 擦净解锁选择、**描迹进出进度不归零**、**断音时间闸门 ≤1 响**、擦过头物理惩罚、A/B/C 三路落盘 |
| 对话布局 | 头像矩形是否在视口内、头像头顶是否高过文本框、对话框是否通铺贴底 |
| 分支 | 资料卡出现且**点得动**（触发后续 flag） |
| HUD | 章节角标含当前章名、返回按钮存在 |
| 烟测 | 12 个章节场景逐一实例化跑 60 帧，活着且有渲染节点 |

## 交互式调试钩子（开发用，正式入口永不触发）

| 参数 | 作用 |
|---|---|
| `-- autostart` | 标题自动点击→转场，8s 后回报"换场到哪个场景、音乐是否停" |
| `-- shot` | 截图存 `data/gen/`（标题/章节画面/资料卡状态），用于人眼验收 |
| `-- auto`（RPGExplo） | 自动驾驶到墓碑（回归用；默认是手动**自由走**）|

## 已知边界

机器只能测"关卡能不能过、flag 对不对、布局在不在界内"；
**观感、手感、叙事节奏**仍需真人（见 `doc/游玩指引.md` 测试附页的观察纪律）。
