## 三条读文档的规矩

**1. 口径冲突时，`剧本.md` 优先。**
它自己第一条就写了：「与 `doc/剧情.md` 冲突之处，以本稿为准」。
（`剧情.md` 已移入 `archive/`。）

**2. 资产归属看代码，不看文档。**
`src/Core/SlotRegistry.cs`（53 个槽位 + Plate P1–P12）是唯一事实来源，
`美术需求.md` 只是它的可读投影。**两边不一致时以代码为准。**

**3. 资产挂"会复用的东西"，不挂章节编号。**
主角已经从「陆昀」改回「老吴」，剧情已经从 2021 换到 2006→2026。
绑在动词上（擦/描/拓/对/量）的资产，剧本怎么改都不作废。
