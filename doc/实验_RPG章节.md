# 实验分支：把后面几章改成「地图走位 + 指引触发」

> 分支：`exp/rpg-探案`（从 main 拉出）。
> 动机：第一章「碑上的名字」是**在地图上操控老吴走动、跟着指引走到目标点触发**
> 的玩法；后面几章原来一进来就是"底图 + 文本框 + 资料卡"。美术后面又补了几张
> 俯视整图（`map_office` / `map_shop` / `map_archive`），在能复用的地方改成同款 RPG。

## 一、做了什么（原型）

- 抽出可复用的走位引擎 `src/Game/RpgWalk.cs`（把 `Dev/RPGExplo` 的经验泛化）：
  地图分类可走面 · 四脚占位 · 八向原地走动（轴分离）· 相机跟随夹边 ·
  目标信标（脉冲环+亮柱+浮标标签）· 顶部指引条 · 走到目标按 Enter 切场景。
- 每张图一份子类配置 + 一个薄场景：
  | 场景 | 地图 | 出生 → 目标 | 触发 |
  |---|---|---|---|
  | `scenes/RpgOffice.tscn` | `map_office` | (460,640) → 电脑前 (500,520) | → `Ch02`（查档） |
  | `scenes/RpgShop.tscn` | `map_shop` | (240,420) → 灯下 (650,650) | → `Ch03`（两个日期） |
- `ChapterFlow.Next()`：二章 / 三章改成先走 `RpgOffice` / `RpgShop`，
  到了目标点再进各自的内容场。`Label()` 同步映射（存档页仍显示正确章名）。

## 二、可走面怎么定的（内景）

和墓园同思路——**按颜色分类**（`RpgWalk.WalkablePixel`，子类可覆盖）：
暖棕 / 红砖地板可走；灰石、白墙、紫陈列、纯黑（档案室透明区）不可走。
离线用 `data/gen/walkprev_*.png` 预览过分类结果（砖地可走、紫陈列排除）。

## 三、怎么再加一章（扩展方法）

1. 写一个 `RpgWalk` 子类（新文件，类名=文件名），设 `MapPath / SpawnWorld /
   Targets / Guidance`；必要时 `override WalkablePixel` 调颜色判据。
2. 加一个 `scenes/RpgXxx.tscn`（`[node type="Node2D"]` + script 指到该 .cs）。
3. `ChapterFlow.Next()` 把该章改成先返回 `RpgXxx.tscn`，`Label()` 加映射。

## 四、已知问题 / 下一步

- **颜色分类偏粗**：书柜、石堆等木色/灰物有少量误判为可走；要精细得改像素级碰撞层。
- **`map_archive` 有大片透明区**（转 RGB 变黑），当整图走位会露黑边；要先用就先
  裁到房间范围（或把透明区补成地板），再登记为 `RpgArchive`。
- **`map_shop` 五场共用**（三/六/七/八/十一章都在铺子）：目前只接了第三章；
  其余章要么各建一个 `RpgShopN`，要么给 `RpgWalk` 加"按存档进度动态选目标场"。
- 走位段是**纯自由走**，没有寻路（不需要，玩家自己走）；墓园那套 BFS 是给自动回归用的。
- `Dev/RPGExplo`（墓园）暂未并入 `RpgWalk`，两条暂时并存；后续可合并。
