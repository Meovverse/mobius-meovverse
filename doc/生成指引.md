# 终章过场动画 · 生成指引（交执行 AI）

> 任务：**12-3「九十秒扒水泥」的循环段视频**。不是整章动画——程序只循环播这一段，
> 总时长、停顿、`sfx_base_crack` 之后的静默都由游戏代码控制（见 §6 接线）。

## 1. 这个镜头是什么

2026 清明，A 区 7 号墓。人群围观中，**老吴（六十多岁）蹲在碑底座前**，
戴手套的手一下一下扒开水泥，露出底下 2006 年他亲手刻的两行日期。
镜头固定在他背后偏上（越肩俯视感），**只有他的手和肩在动**。没有音乐，
只有水泥碎屑声（音轨不进视频，程序另行播放）。

情绪参考词：**执拗、安静、慢**。不是愤怒，不是悲情——是一个手艺人
在二十年后收回自己写下的一句话。

## 2. 硬性规格（一票否决项）

| 项 | 值 |
|---|---|
| 分辨率 | **640×360**（游戏原生，勿高勿低——高清反而要和像素风对质） |
| 帧率 | **8 fps**（故意低帧，和游戏动画一致） |
| 时长 | **4.0s 整 = 32 帧**（程序按 90s÷4s 循环 22.5 次，任意截取都无缝） |
| 循环 | **第 32 帧与第 1 帧连续无缝**（验收重点，见 §7） |
| 容器 | webm（VP9）首选；备用 theora `.ogv`。Godot `VideoStreamPlayer` 直接吃 |
| 色板 | 全片灰阶 ≤ **10 色** + 唯一一处低饱和红（苏航方向人群里一点衣服色，可选） |
| 光源 | 左上 45° 固定，全程不许变 |
| 禁止 | 正脸（任何人脸）、可读文字、镜头推拉摇移、BGM、渐入渐出、变速 |

## 4. 方案 A（主选）：四张关键帧 + 脚本合成

### A-1 先画 4 张关键帧（本任务唯一的美术活）

尺寸 **64×120 透明底 PNG**，命名并放到 `assets/textures/cutscene/`：

- `wu_crouch_01.png` 蹲姿起手：重心落下，右臂前伸**刚触到**水泥面
- `wu_crouch_02.png` 扒：右手带起一块，手臂抬起 ~14px，肩随之前倾 2px
- `wu_crouch_03.png` 落：手回到接近 01 的高度，指缝带碎屑
- `wu_crouch_04.png` 微幅抬头看底座（头比 01 高 1px 即可，**别画脸，永远背面**）

姿势铁律：蹲姿总高约 78px（站姿 120 → 塌下 1/3）；**右臂是画面里唯一的
大幅度运动**；头/躯干在四帧间位移 ≤2px。四帧的轮廓像素必须 85% 以上重合
（只有手臂区不同）——这是循环不跳的保证。

### A-2 合成脚本（任何 AI 都能跑，无随机数）

```gdscript
# Godot 4 headless 执行：逐帧摆场景 → 存 PNG → ffmpeg 合 webm
var frames := ["wu_crouch_01","wu_crouch_02","wu_crouch_03","wu_crouch_04"]
# 32 帧分配：循环 8 次动作循环 = 01,01,02,03 各 2 帧 × 2 组 + 04 双拍收尾
#   节奏：扒(02)占 1 帧、其余 2 帧——慢，不规律感靠"01 多停一帧"
# 每帧背景: bg(去色清明图放大) + stele_A7_full(scale 2.6, 右下) + 老吴(中偏左)
# 粒子: ProcGen.DustParticle 贴图, 02 帧起在手掌下撒 3~6 颗, 自由落体 2 帧消失
for i in 32:
    draw_frame(frames_map[i])          # 固定机位, 无 camera 运动
    save_png("user://seq/f%02d.png" % i)
```

```bash
ffmpeg -framerate 8 -i seq/f%02d.png -c:v libvpx9 -pix_fmt yuva420p \
       -b:v 400k out/cutscene_wu_chisel.webm
```

（无 Godot 环境时，纯 ffmpeg+PIL 合成同一逻辑也可——关键只在**确定性**。
禁止任何扩散模型逐帧生成：帧间漂移会让循环段变成果冻。）

## 5. 方案 B（备选）：图生视频 AI

仅当 A 的蹲姿四帧画不出来时用。

1. **首帧**用图像 AI 生成（提示词见下），人工审核通过后作为**唯一**图生视频输入。
2. 图生视频参数：时长 ≤4s；运动幅度**最低档**；关闭一切镜头运动。
3. 提示词（首帧）：
   `back view of an elderly chinese stonemason in his sixties crouching in front of a granite headstone base, peeling off grey cement with gloved hands, public cemetery, overcast, seen from behind and slightly above, muted greyscale, 16-bit pixel art, 640x360, no face visible`
   负向：`face, text, letters, camera motion, zoom, blur, gradient, colorful, smooth shading, modern clothes, snow`
4. **已知失败模式（直接判废重跑）**：手穿进石头里 / 帧末姿势漂移回不去帧初（循环断）/
   人物突然转头 / 画面变高清写实 / 背景人群动起来。
