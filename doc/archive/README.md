## 什么时候可以删

这三份文档**可以随时删掉**，它们对实现没有任何作用。
但建议等 `剧本.md` / `分镜稿.md` 稳定两周之后再删——
在这之前，如果又出现"哪一版才对"的问题，它们是对照答案。

**一条经验**：这个项目已经换过两次版了（初稿 → 剧情 → 剧本），
每次都是靠旧稿才查出来"我改错了哪一处"。
所以在换版稳定之前，别删。
