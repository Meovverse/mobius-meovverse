# 一块碑 · 分镜稿（像素 · 640×360 · 按时间顺序）

> 配套：`doc/剧本.md`（分场与台词）· `doc/玩法设计.md`（六动词）· `doc/美术需求.md`（7 张图）· `doc/技术方案.md`（SurfaceModel / 放大镜显影）· `doc/音频需求.md`（音效 ID）
> **依据**：`一块碑_修改版剧情.md`（最新口径）——**2006 年 4 月 → 2026 年清明，二十年冷案**。
> 排法：**与剧本同一时间顺序**（甲部 2006 / 乙部 2026）。每一镜都标了**时间**，方便对着剧情日历走。

## 0 · 硬规格

| 项 | 值 |
|---|---|
| 原生分辨率 | **640×360**（16:9） |
| 放大 | 只允许整数倍：2×／3×／4×；**禁双线性过滤** |
| 石面本体 | 程序生成 `SurfaceModel`（`Height` / `Dust` / `Pile` / `BatchMap` 四张场），**不读美术图** |
| 石面两层 | **Base**（字形块面 + 大明暗）+ **Detail**（刀口毛边）——**Detail 只在放大镜里显影** |
| 放大镜 | **不是放大图像，是在 4× 窗口里显影 Detail 层**——分辨率限制从敌人变帮手 |
| 中文字体 | 12×12 点阵，一行 40–48 字（对白框内 24 字） |
| 调色板 | **近乎全灰**；**朱红只用于印章与标语**；深蓝改为**只用于"档案/遗像"那一屏**（旧案的苏老师已不存在） |
| 光标 | 一个：放大镜环（程序 Draw API 画，正圆）→ 描时变錾子尖 → 拓时变拓包 → 量时变卡尺 |
| 人物 | 独立槽位；**背景图里不许画人** |

**禁令**：慢推 · 缩放 · 摇镜 · 叠化 · 景深 · 粒子 · 旋转 · 半透明 · 玻璃反光 · 抗锯齿描边 · 红框高亮 · 提示箭头 · **任何"发现矛盾"的系统提示**。
**允许**：硬切 · 材质帧动画 · 换色板（2006 暖旧 / 2026 冷灰 / 清明雾）· 棋盘抖动 · 光标 1:1 跟随。

**Detail 层的画法（第一章的命）**
阴刻字＝上缘 1px 高光 + 下缘 1px 阴影。**新刻的刀口是利的**（笔画平齐、收笔无缺口），**原来的刀口是钝的**（收笔留 1px 缺口）。
第一章两处改动（「兰」字最后一笔 · 「16」底下的「17」）全部建立在这 1px 上。**别省。**

## 3 · 六动词的反馈规范

| 动词 | 光标 | 帧数 | 失败长什么样 | 音效（真实 ID） | 不许出现 |
|---|---|---|---|---|---|
| **看** | 放大镜环（正圆）＋ 4× 显影 Detail | 跟随 1:1，无缓动 | 没有失败——但**擦过头的地方永久变糊** | 细沙声 | 高亮、红框、箭头 |
| **擦** | 镜内＝布/手 | 3 层粉末各 4 帧 | 擦过头＝碎屑压进缝，对比度永久下降且不可逆 | `sfx_brush_pile` / **`sfx_over_wipe`** | 进度条、次数提示 |
| **描** | 錾子尖 | 每格 2 帧 | 偏出容差＝断，**从断点重来**（不自动吸附） | `sfx_trace_start` / `sfx_trace_break` / `sfx_trace_done` | 自动修正、路径预览 |
| **拓** | 拓包 | 每次点按 4 帧，墨色 8 级 | 轻了不清、重了糊、揭太早 | `sfx_rub_tap_light/mid/heavy` / `sfx_rub_blur` / `sfx_peel_paper` | 进度条、力度提示 |
