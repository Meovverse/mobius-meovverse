## 一、先做这 5 个（如果你只有一天）

这 5 个不是"最重要的几个音"，是**整个音感设计的地基**。

### 1. 🟢 `sfx_over_wipe` · 擦过头 · 0.4s

**这是整个游戏最重要的一条音效。**

玩法规定：**玩家按住右键擦石粉。擦过头会把碎屑压进刻痕里，那一处永远看不清了。**
游戏不给他任何文字提示，只有这个声音。

所以它必须**让人本能地想停手**——
不是"错误提示音"那种刺耳，而是一种**"糟了"**的感觉：闷、堵、一点点发涩。
像铅笔划过纸突然戳进一个坑。

> ★ 判断标准只有一条：**听到它，玩家的手会离开鼠标吗？**
> 会 → 过。不会 → 重做。

### 2. 🟢 `sfx_trace_break` · 描断了 · 0.3s

玩家要沿刻痕一笔一笔「描」下来，描偏了就断，必须**从断点重来**（不是从头）。

声音应该像**脚滑了一下**——一个短促的"停"。
让玩家立刻知道"从这儿接上"，而**不是**"我做错了什么"。
这个区别很重要：前者是纠正，后者是惩罚，而这里是纠正。

### 3. 🟢 `loop_chisel_run` · 走刀（描的时候按住）· 2–4s 可循环

**必须无缝循环。** 玩家会按住描 5 秒以上，循环点在第 3.2 秒响一下，
整个手感就从"我的手在动"变成"一段音频在播"。

- 錾子连续走刀的声音
- **有节奏但不机械**——每 4–6 下一记
- 频率重心压在 200–2000 Hz（太尖会跟像素风打架）

### 4. 🟢 `sfx_peel_paper` · 揭拓片 · 0.8s

玩家拓完一张片子（把碑面的证据拓到纸上），然后**把纸从石头上揭下来**。

**这是玩家在这个游戏里拿到的第一个证据。**它离手的感觉要写实。

- 纸从石面上**一点点**分离，最后一下略快
- **绝不能是"唰"的一声**——那样像撕纸，不像揭拓片
- 这一条**自己录最准**：拿一张纸压在石板上慢慢揭，手机贴近录就行

### 5. 🟢 `sfx_stone_grind` · 磨碑 · 1.5s

玩家选择**把那块碑整个磨掉**——销毁证据，30 秒不可逆演出。

声音要有**从远到近再停**的走向，因为玩家是在做一件不可逆的事。
石粉落一地，白色的，像雪。

## 六、技术规格

### 6.1 格式

| | 一次性音效 | 循环音（环境 + 持续动作） |
|---|---|---|
| 容器 | **WAV**（短音解码零延迟） | **OGG Vorbis** |
| 采样率 | **44100 Hz** | 44100 Hz |
| 位深 | 16-bit PCM | — |
| 声道 | **单声道** | 单声道 |
| 时长 | 见各条 | 环境 20–40s；持续动作 2–4s，**必须无缝** |

### 6.2 ★ 响度必须分级

不同来源的素材拼在一起，最常见的失败是**响度不一**：
某个音比别人大 6 dB，玩家会觉得"这个动作更重要"，于是被误导。

| 级别 | 峰值 | 用在哪 | 例子 |
|---|---|---|---|
| **S0** 触觉级 | **−20 dBFS** | 笔触级反馈。手在动，声音很轻 | 擦石粉、走刀、卡尺滑动 |
| **S1** 操作级 | **−14 dBFS** | 界面操作 | 翻页、揭纸、写字 |
| **S2** 事件级 | **−8 dBFS** | 一次性事件。**全篇最响的就是这一级** | 撕纸、砸、底座裂开 |
| **A** 环境 | **−30 dBFS** | 环境循环。**必须几乎听不见** | 风、雨 |

**交付时请附一个响度表（文件名 + 峰值 dBFS）。**

### 6.3 无缝循环的验收标准

- 首尾拼接处**不能有爆音**（click / pop）
- 首帧和尾帧的直流偏移差值 < 0.005
- 做法：录的时候**首尾各多录 1 秒**，做 200ms 等功率交叉淡化

### 6.4 三条禁止

| 禁止 | 为什么 |
|---|---|
| ★ **任何 BGM / 旋律 / 和声** | 设计上定死了"全篇没有 BGM"。一个音阶都别加 |
| ★ **"叮咚"/"确认"/"成就"式 UI 提示音** | ★ 最大的诱惑。玩家抄对日期时**不该听到"正确"**，只该听到笔尖的声音。加了这条，整个游戏就从"有人在查一件事"变成"一个记账 App" |
| 金属铃声、App 通知音、系统提示音 | 同上 |

另外：频谱重心压在 **200–2000 Hz**。素材库里那些频谱很宽、金属感很强的音效
（大量商业音效的默认审美）会跟像素风打架——这个游戏的声音要**土**、要**近**、要**闷**。

## 七、复用性说明（为什么这么排）

策划的修改会影响剧本，但**不会影响动词**。所以：

```
剧本可能改的：  人物名 · 章节数 · 结局 · 场景顺序 · 谁在哪一章
剧本不会改的：  六个动词本身 · 「擦过头」有代价 · 「拓片会带走改动」· 「账本记两行」
                      ↓
              这些都长在动词上，所以 🟢 的部分永远不作废
```

**这就是这份文档把动词音排在最前面的原因**：
即使剧本整个推翻重写，这 20 个音一个都不会白做。

需要改名的只有一处：**老吴**（刚从「陆昀」改回来）。
如果剧本里还有别的改名，动词音不受影响。
