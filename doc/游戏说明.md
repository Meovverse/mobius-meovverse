# 墓时 · 游戏说明

## 游戏简介

《墓时》是一款 2D 像素悬疑推理游戏。你是石刻匠**老吴**。二十年前，你亲手为一位母亲刻下墓碑；二十年后你发现，碑上的日期对不上——**石头是你一刀一刀刻的，你记得每一笔**。

擦开碑身的浮尘、描下被磨过的刻痕、把两张纸并起来对着光看、用卡尺量那两个日期——用你的手，一层层挖出被埋了二十年的真相。四个失败结局，一个真结局。

> 一句话：**石头不会撒谎。会撒谎的，是人。**
