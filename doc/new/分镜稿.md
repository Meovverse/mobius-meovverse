## 0 · 硬规格

| 项 | 值 |
|---|---|
| 原生分辨率 | **640×360**（16:9） |
| 放大 | 只允许整数倍 2×／3×／4×；**禁双线性过滤** |
| 石面本体 | 程序生成 `SurfaceModel`（`Height`/`Dust`/`Pile`/`BatchMap`），**不读美术图** |
| 石面两层 | **Base**（字形块面 + 大明暗）+ **Detail**（刀口毛边）——**Detail 只在放大镜里显影** |
| 放大镜 | 不是放大图像，是**在 4× 窗口里显影 Detail 层** |
| 中文字体 | 12×12 点阵（对白框内 24 字/行） |
| 调色板 | **近乎全灰**；**朱红只用于印章与标语**；**深蓝只用于"档案/死亡证明"那一屏** |
| 光标 | 一个：放大镜环 → 描时錾子尖 → 拓时拓包 → 量时卡尺 |
| 人物 | 独立槽位；**背景图里不许画人** |

**禁令**：慢推 · 缩放 · 摇镜 · 叠化 · 景深 · 粒子 · 旋转 · 半透明 · 玻璃反光 · 抗锯齿描边 · 红框高亮 · 提示箭头 · **任何"发现矛盾"的系统提示**。
**允许**：硬切 · 材质帧动画 · 换色板（2006 暖旧 / 2026 冷灰 / 清明雾）· 棋盘抖动 · 光标 1:1 跟随。

**调查选择的镜头语言（新剧情的关键）**
**"调查选择"不是弹窗，是把光标放到某样东西上**：
- 选 **A**：光标（放大镜/錾子）**留在石头上** → 画面不动，Detail 层继续显影；
- 选 **B**：光标**移到纸上** → 硬切到桌面，纸被拖进画面；
- 选 **C**：光标**离开画面**（他起身走了）→ **硬切黑场**，这一支的代价用黑场时长（2 秒）表示。
**永远不给"【调查】"三个字。**

**Detail 层的画法（第一章的命）**
阴刻字＝上缘 1px 高光 + 下缘 1px 阴影；**新刻的刀口是利的**（笔画平齐、收笔无缺口），**原来的刀口是钝的**（收笔留 1px 缺口）。第一章的两处改动全部建立在这 1px 上。**别省。**

## 3 · 六动词的反馈规范

| 动词 | 光标 | 帧数 | 失败长什么样 | 音效（真实 ID） | 不许出现 |
|---|---|---|---|---|---|
| **看** | 放大镜环（正圆）＋ 4× 显影 Detail | 跟随 1:1，无缓动 | 没有失败——但**擦过头的地方永久变糊** | 细沙声 | 高亮、红框、箭头 |
| **擦** | 镜内＝布/手 | 3 层粉末各 4 帧 | 擦过头＝碎屑压进缝，对比度永久下降且不可逆 | `sfx_brush_pile` / **`sfx_over_wipe`** | 进度条、次数提示 |
| **描** | 錾子尖 | 每格 2 帧 | 偏出容差＝断，**从断点重来**（不自动吸附） | `sfx_trace_start` / `sfx_trace_break` / `sfx_trace_done` | 自动修正、路径预览 |
| **拓** | 拓包 | 每次点按 4 帧，墨色 8 级 | 轻了不清、重了糊、揭太早 | `sfx_rub_tap_light/mid/heavy` / `sfx_rub_blur` / `sfx_peel_paper` | 进度条、力度提示 |
| **对** | 手 + 纸 | 叠合 6 帧 | 叠不齐看不出印痕 | `sfx_paper_slide` / `sfx_paper_lift` | **任何"发现矛盾"的提示** |
